# Интерфейс oko

Редизайн встроен в существующий FastAPI сервис. Веб часть осталась на HTML, CSS и JavaScript без сборки и внешнего игрового движка. Существующие запросы загрузки и получения результата сохранены. Добавлен защищённый `GET /api/v1/capabilities`: экран проверяет ключ и получает реальные ограничения размера видео. Ключ хранится только в памяти страницы.

## Пользовательский сценарий

На первом экране — живой Overworld, подвесная деревянная вывеска, API ключ с переключателем видимости и START ANALYSIS. Переход через обсидиановый портал занимает 2 секунды и имеет кнопку пропуска. В Nether слово UPLOAD собирается из шести отдельно падающих букв. Загрузка файла и запуск анализа выполняются отдельными действиями.

Плеер использует настоящий HTML video. Доступны пауза, звук записи, шкала времени, фиксированная лупа 1×/2× и полноэкранный режим. Клик по таймкоду в чате перематывает запись. Кадры-доказательства открываются в диалоге, нормативная ссылка — отдельно. Возврат в приветствие ставит видео на паузу и сохраняет файл, позицию, результат и ключ до закрытия/перезагрузки страницы.

Звук сайта и звук видеозаписи управляются отдельно. Звуки сайта включаются явным действием. Декоративное движение можно выключить; `prefers-reduced-motion` учитывается автоматически. Декорации приостанавливаются в скрытой вкладке.

## Запуск

Полный сервис: `./start.ps1` или `docker compose up --build -d`, адрес `http://localhost:8000/`. Для обработки требуется подключённая локальная модель, как описано в README.

Локальный просмотр интерфейса без Docker: `./preview.ps1` или `py qa/serve_preview.py`, адрес `http://127.0.0.1:8765/`. Этот просмотр запускает настоящий API, но не отдельный обработчик очереди. Для полного анализа запустите обработчик и предоставьте модель, FFmpeg и FFprobe. Продуктовый интерфейс не содержит демонстрационных нарушений или подмены ответа модели.

## Музыка и атмосфера

Подключены предоставленные пользователем оригинальные файлы, без перекодирования, изменения темпа или высоты тона:

- `web/assets/music/overworld.m4a` — Overworld, 208,61 с.
- `web/assets/music/netherworld.m4a` — Nether, 295,20 с.

Все настройки находятся в `web/config.js`: `audio`, `portal`, `atmosphere`. Базовая музыка 0,10, предел при просмотре видео 0,03, портал 0,18, короткие SFX 0,10. По измерениям полных дорожек и трёх громких фрагментов Nether дополнительно ослаблен на 1,5 dB (×0,841395). Overworld не усилен. Отчёт: `qa/music_measurements.json`. Громкость проверена измерениями и браузерным воспроизведением; субъективное прослушивание не выполнялось.

Музыка включается существующей кнопкой звука с учётом сохранённого выбора. До play устанавливается нулевой уровень. Первое нарастание — 1200 мс, выход — 400 мс, вход — 1000 мс; при видео приглушение — 300 мс, восстановление — 750 мс. Для музыки используется единственная ступень уровня HTMLAudioElement.volume, без повторного GainNode. На каждый мир создан максимум один элемент, позиция сохраняется, неактивный трек останавливается. У границ loop действует короткая огибающая 200 мс. Mute немедленно обнуляет музыку и SFX и отменяет fade; скрытая вкладка останавливает воспроизведение. Неудачная загрузка трека запоминается без повторного запроса.

Портал — отдельный Canvas 320×180, целочисленный масштаб, без сглаживания. Фазы 0–250 / 250–700 / 700–1200 / 1200–1650 / 1650–2000 мс управляются одним временем; сцена меняется под непрозрачным слоем на 1350 мс. Сборка UPLOAD запускается после завершения. При reduced motion / выключенном движении переход — спокойное затухание 220 мс.

У Overworld из исходного изображения выделены две маски крон; пиксели маски удалены из неподвижной основы и восстановлены ближайшими незамаскированными пикселями. Сдвиг листвы — один базовый пиксель, циклы 5,4 и 6,7 с. Максимум 6 листьев, на телефоне 2. Nether — максимум 6 частиц пепла и 2 искры, на телефоне 3 и 1. Искры выбирают яркие точки самой лавы. Частицы вырезаются по фактическим границам интерфейса с отступом; маски обновляются при resize, scroll, изменениях размеров и открытии диалогов. Скрытая вкладка и отключённое движение останавливают декоративные циклы без накопления частиц.

## Ассеты

Источники, версии, контрольные суммы, условия использования и промпты перечислены в `ASSETS.md` и `ASSET_MANIFEST.json`. По умолчанию используются два созданных пейзажа, собственные SVG текстуры, пиксельный гаст и тихие процедурные SFX. Шрифт Press Start 2P поставляется локально вместе с SIL OFL.

Оригинальные материалы Java Edition 1.21.10 находятся в `private_asset_pack/minecraft/1.21.10/`. Для частного локального просмотра можно задать `ENABLE_LOCAL_GAME_ASSETS=1` перед запуском API. Тогда защищённый ответ capabilities укажет необязательный пакет, а интерфейс подключит текстуры и настоящие тихие игровые SFX. Пакет выключен по умолчанию и исключён из Docker контекста и Git. Права на его публичное распространение не подтверждены. Публичная сборка использует заменяемые собственные материалы. Все 4 исходных звуковых объекта проверены по хешам локального индекса; несовпадение хеша самого индекса с metadata версии отмечено в приватном manifest.

## Изменённые файлы

- `web/index.html`, `web/styles.css`, `web/app.js`: структура, оформление, загрузка и состояния анализа.
- `web/worlds.js`: сцены, фоновые слои, частицы, портал, сборка букв и управление движением.
- `web/player.js`: воспроизведение, таймкоды, лупа и fullscreen.
- `web/chat.js`: реальные события, выбор эпизода, кадры и источники.
- `web/audio.js`, `web/config.js`: единый менеджер звука, музыка, уровни, таймлайн портала и параметры атмосферы.
- `web/assets/`: пейзажи, шрифт и собственные текстуры.
- `app/api.py`: выдача статических ресурсов, capabilities, подключение приватного локального пакета по флагу и корректный отказ для не ASCII ключей.
- `.gitignore`, `.dockerignore`, `.env.example`: исключение приватных данных и необязательный локальный пакет.
- `preview.ps1`: запуск локального просмотра без Docker.
- `tests/test_service.py`, `qa/`: серверные, браузерные и визуальные проверки.

## Проверка и ограничения

Проверены Chrome, размеры 1366×768, 1920×1080 и 390×844, отсутствие горизонтальной прокрутки, неверный и отсутствующий ключ, выбор неподдерживаемого расширения, H.264 в MOV, pause/play, seek, лупа 1×/2×, fullscreen, отдельный mute видео, переключатель SFX, пропуск портала, быстрое возвращение через историю, сохранение состояния, reduced motion, блокировка AudioContext и однократный отказ отсутствующего трека без повторных запросов. ProRes в MOV вызывает понятное сообщение о несовместимом кодеке и сохраняет отправку на анализ.

Браузерные проверки результата используют явно обозначенные ответы только в тестовом перехватчике Playwright: события, кадры, отсутствие событий, отказ модели, HTTP 500 и длинный список. В продуктовой странице этих ответов нет. Все 7 серверных тестов прошли с отдельной временной базой. Шрифт проверен по таблице cmap: все 85 проверяемых букв и знаков присутствуют. Отказ загрузки необязательного фона также не блокирует интерфейс.

Качество распознавания не проверено: веса модели и датасет не предоставлены. Автоматического перекодирования MOV для браузера пока нет; сервер принимает MOV независимо от поддержки кодека браузером. Safari и Firefox здесь не запускались. Docker на машине отсутствует, контейнерная сборка не запускалась.

### Проверки доработки атмосферы

`py qa/audio_atmosphere_check.py` проверяет настоящие M4A и их длительности, нулевую начальную громкость, уровни, видео duck/restore, mute, loop, позиции, приватный portal SFX, порядок UPLOAD, отмену перехода, быстрый возврат, скрытую вкладку, reduced motion, мобильный размер и отсутствие лишних POST анализа. Каждый фон наблюдается 26 секунд, проверяются пределы числа частиц и прозрачность слоя под панелями. Результат: `qa/atmosphere_audio_results.json`. Скриншоты находятся в `qa/portal-*.png` и `qa/refined-*.png`.

Кнопка звука продублирована только на слое портала и синхронизирована с основным переключателем: немедленный mute доступен обычным нажатием во время перехода. Если панели закрывают участок фона, пепел выбирает свободную точку ограниченным числом попыток; искры появляются только возле доступных точек лавы.

### Начальные экраны из второго проекта

Поля, bitmap-шрифт, кнопки и последовательность до рабочего пространства перенесены из `AmirBro0/2`, commit `8983c777fb136c50c9c081d949b2e4f9b113c9da`. Сохранён текущий закатный `cherry-grove.png`, его палитра и эффект лепестков. Панорама второго проекта не подключается. Основной интерфейс использует Monocraft; заглавная вывеска получила собственные аккуратные Ender-глаза, дубовую текстуру и полные цепи.

`ServerIntro` проверяет ключ через настоящий `POST /ui/v1/session`. Пустой/неверный ключ и отказ соединения показывают отдельные экраны. После успешного ответа идут карта загрузки участков мира и переход в Nether с URL `#analysis`; карта — оформление подготовки интерфейса, она не запускает анализ видео. Отмена прерывает запрос и игнорирует запоздалый ответ. Ключ не сохраняется в браузерном хранилище и очищается после входа. Следующие переходы между мирами используют прежний портал.

`qa/server_intro_browser.py` проверяет вход, ошибки, отмену, поздние ответы, повторный вход, последовательность загрузки и навигацию Nether → End → Nether в отдельном Chrome с тестовыми ответами API. Адаптивные размеры: 1920, 1366, 390 и 320 px; результаты — `qa/server-intro-results.json`. Проверка кэша и всех ресурсов в Chrome: `qa/chrome_asset_release_check.py`, результаты — `qa/chrome-asset-release-results.json`.
