# Требования ForteBank и реализация OKA

Основание: предоставленный пользователем «Кейс_ForteBank.docx», прочитан 18.10.2026. Документ определяет требования продукта, а не инструкции доступа к компьютеру.

| Требование | Реализация / ограничение |
|---|---|
| Загрузка оригинального видео и автоматический запуск | UI → очередь сайта → API нашего Qwen; модель сама готовит кадры |
| Статус обработки | Очередь / анализ / доказательства / готово / ошибка |
| Два итоговых вердикта | «Нарушение не обнаружено» / «Обнаружены признаки возможных нарушений»; техническая ошибка отдельно |
| Несколько событий с типом и описанием | Сохраняются все события из завершённого ответа модели |
| Таймкод и 1–3 JPEG | Время и байты берутся из ответа модели; проверяются формат и диапазон видео |
| Начало, момент, конец | Из подробного отчёта модели; неизвестные значения явно показаны |
| Нормативное основание | Акт, пункт, ссылка, пояснение и статус юридической проверки; вымышленные статьи не добавляются |
| POST /api/v1/analyze, multipart file | Поддерживается |
| GET /api/v1/jobs/{job_id} | Поддерживается; processing/done/failed |
| X-API-Key | Неверный/отсутствующий ключ → 401 |
| До 300 секунд с очередью | Контроль в worker; просроченный анализ → failed. Успешность любого видео в пределах лимита ещё не доказана |
| Собственное локальное AI-решение | Код в engine/, локальные веса, сервер команды; сторонние AI API не используются |
| Работа без интернета после подготовки | Зависимости и веса устанавливаются заранее, сайт и модель общаются локально |
| Без аудиоанализа и идентификации лиц | Конвейер не выполняет эти задачи |
| Без подгонки под тестовые ответы | Excel/эталоны не входят в конвейер и GitHub-проект |
| Публичный URL и ключ жюри | GitHub-репозиторий не является работающим сервисом. Нужны действующий GPU API, HTTPS-развёртывание и проверка URL |
| Качество обнаружения / устойчивость | Нужна оценка на отложенных видео. Тесты API не являются accuracy |
| Коммерческая применимость | Требуется проверка лицензий весов, детекторов и оформления перед коммерческим выпуском |

Кейсовый бинарный вердикт не означает обвинение сотрудника. Возможные события и юридическая применимость передаются человеку на проверку. Дополнительные таблицы по моментам и экспорт подробного JSON сохраняют информацию за пределами компактного контракта жюри.
