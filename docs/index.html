OKO анализирует видеозаписи с помощью Qwen3-VL, отмечает моменты для проверки и показывает кадры-доказательства. Итоговое решение остаётся за человеком.

Что делает OKO

Смотрит запись

Принимает исходное видео и выбирает моменты, где нужен подробный анализ.

Отмечает события

Связывает наблюдения с таймкодами и исходными кадрами без выдуманных доказательств.

Помогает проверяющему

Показывает возможные нарушения, спорные моменты и причины неопределённости.

О публичной версии: эта страница размещена на GitHub Pages. Обработка видео требует отдельного защищённого API и GPU-сервера; на GitHub видео не загружается и анализ здесь пока не запускается.
